# Infinix Visual (заготовка)

Fabric-мод для Minecraft 1.21.4.

## Что уже есть
- Кастомное главное меню: чёрный фон, надпись "Infinix Visual", только две кнопки —
  "Одиночная игра" и "Сетевая игра" (остальные ванильные кнопки убраны).
- Пустое меню-заготовка, открывается по правому Shift во время игры.
  Пока без функций — просто чёрная панель с заголовком.

## Самый простой способ — собрать через GitHub (ничего не ставить на компьютер)

1. Зайдите на github.com, создайте бесплатный аккаунт (если ещё нет).
2. Нажмите **New repository**, дайте любое название (например `infinix-visual`), сделайте его **Public**, создайте.
3. На странице репозитория нажмите **uploading an existing file** (или "Add file" → "Upload files").
4. Перетащите туда **всё содержимое** папки `infinix-visual` (все файлы и папки из этого архива, включая скрытую папку `.github`) и нажмите **Commit changes**.
5. Откройте вкладку **Actions** вверху репозитория — сборка запустится сама автоматически (займёт 2-4 минуты). Если не запустилась — нажмите на workflow "Build mod" слева и кнопку **Run workflow**.
6. Когда появится зелёная галочка — откройте этот запуск, внизу страницы будет **Artifacts** → `infinix-visual-jar` — скачайте, там будет готовый `.jar`.
7. Распакуйте, киньте `.jar` в папку `mods` вашего Fabric-клиента.

Так GitHub сам скачает всё нужное и соберёт мод — вам не нужно ставить Java, Gradle или IntelliJ.

## Как собрать .jar (вручную, на компьютере)

Мне не удалось скомпилировать jar в этой среде — нет доступа в интернет
для загрузки Minecraft/Fabric/Yarn зависимостей через Gradle. Собрать
нужно у себя, это займёт 5-10 минут:

1. Установите **JDK 21** (Temurin/Adoptium).
2. Установите **Gradle** (или используйте IntelliJ IDEA — она сама всё скачает).
3. Распакуйте архив, откройте папку в терминале.
4. Если нет файла `gradlew` — выполните один раз: `gradle wrapper`
   (нужен установленный Gradle >= 8.8).
5. Соберите мод:
   - Windows: `gradlew.bat build`
   - macOS/Linux: `./gradlew build`
6. Готовый .jar появится в `build/libs/infinix-visual-1.0.0.jar`.
7. Положите его в папку `mods` вашего Fabric-клиента
   (нужен установленный **Fabric Loader** и **Fabric API** для 1.21.4).

## Проще всего
Откройте папку проекта в **IntelliJ IDEA** (Community, бесплатная) —
она предложит импортировать Gradle-проект и сама скачает зависимости,
задачу `build` можно будет запустить прямо из панели Gradle справа.
